# หน้าต่างเตือน DM Remission ใน HOSxP

เพิ่ม **บล็อกต่อท้าย `SYS_VN_SCRIPT`** (script เดียวกับหน้าต่างเตือนสงสัย Sepsis) — ส่วน Sepsis/SOS/MEWS ทำงานเหมือนเดิม
บล็อกมีตัวแปรของตัวเอง (ขึ้นต้น `rm`) อยู่ระหว่างบรรทัด `// === NCD DM REMISSION ALERT ... ===` ติดตั้งซ้ำ = แทนที่บล็อกเดิม

## เตือนเมื่อไหร่
ตอนกดบันทึกหน้าซักประวัติ/ตรวจ (ข้ามหน้าสั่ง Lab และหน้ารายละเอียด ER) ของผู้ป่วยที่
1. มีรหัสกิจกรรม **1I20** (NCDs remission clinic) และ
2. **HbA1c ล่าสุด < 6.5** และ **ไม่ได้รับยาลดน้ำตาลตั้งแต่วันที่ตรวจนั้น**

| สถานะ | ข้อความท้ายหน้าต่าง |
|---|---|
| ผลล่าสุดยังไม่ครบ 90 วัน | นัดเจาะ HbA1c ครั้งถัดไปเมื่อครบ 90 วัน (อีก N วัน) |
| 90–180 วัน | ถึงช่วงเจาะ HbA1c ครั้งถัดไปแล้ว — ควรเจาะวันนี้ |
| เกิน 180 วัน | ผลล่าสุดเกิน 180 วันแล้ว — ควรเจาะ HbA1c วันนี้ |

ทุกกรณีขึ้น **"ห้ามสั่งยาลดน้ำตาล — จะเสียสิทธิ์เบิกงบ DM Remission"**

หน้าต่างแบบเดียวกับหน้าต่างเตือน Sepsis (โทนม่วง แยกจาก Sepsis ที่เป็นน้ำเงิน/แดง): แถบหัว "DM REMISSION : ห้ามสั่งยาลดน้ำตาล" ·
บรรทัดเวลานัดเจาะ · กล่องเนื้อหา HbA1c ล่าสุด/จำนวนวัน + สิ่งที่ต้องทำ 4 ข้อ · ปุ่ม "รับทราบ"
ถ้าผู้ป่วยเข้าเกณฑ์ Sepsis ด้วย หน้าต่าง DM ขึ้นหลังกดรับทราบที่หน้าต่าง Sepsis
หน้าต่างนี้เป็นตัวเตือนหน้างาน · สถานะการเบิกละเอียด (ครั้งที่ 1/2/3, lifestyle 180 วัน, หยุดยา 90 วัน, ยอดเงิน)
ดูที่ NCD Dashboard หน้า DM → "เบิกงบบริการ DM Remission" (เปิดในเครือข่าย รพ.)

ตรวจกับข้อมูลจริง 14 พ.ย. 2569 (ผู้ลงทะเบียน 239 ราย): SQL ใน script ให้ผลตรงกับตรรกะ Python ทุกราย ·
ผู้ป่วยที่อยู่ในช่วงห้ามสั่งยา (รอ/ถึงกำหนดเจาะครั้งที่ 2 และ 3 = 106 ราย) ขึ้นเตือนครบทุกราย · รวมจะเตือน 158 ราย ไม่เตือน 81 ราย
เวลาที่เพิ่มต่อการบันทึก ~60 มิลลิวินาที (ตาราง pp_special ไม่มี index ที่ hn) — คำสั่งอื่นทำเฉพาะผู้ลงทะเบียน 1I20

## ผลทดสอบ
- 14 พ.ย. 2569 รพ.วังน้ำเขียว (HOSxP 3.69) ฐานจริง ติดตั้งโหมด `--demo-hn` กับระเบียนผู้ป่วยทดสอบ
  (ระเบียนทดสอบที่ถูกบันทึกว่าเสียชีวิตเปิด visit ไม่ได้ — เลือกรายที่ `patient.death = 'N'`) → บันทึกหน้าซักประวัติแล้วขึ้น RM2 / RM3 / RM4
  และหน้าต่างม่วง DM REMISSION ครบ = HOSxP แปลและรันบล็อกผ่าน · จากนั้นติดตั้งแบบปกติ (ไม่มี demo)

## ทดสอบบนฐานจริงเมื่อไม่มีฐานทดสอบ
`install ... --demo-hn <HN ผู้ป่วยทดสอบ>`: ข้อความ RM2-RM4 + บังคับหน้าต่าง DM **เฉพาะ HN นั้น** ผู้ป่วยอื่นทำงานปกติ ·
หา HN ผู้ป่วยทดสอบที่ยังไม่ถูกบันทึกเสียชีวิต (patient.death = 'N') · ผ่านแล้ว `install` ซ้ำโดยไม่ใส่ `--demo-hn` ·
ถ้าไม่ขึ้นอะไรเลย = script แปลไม่ผ่าน ให้ `remove` (ถอดเฉพาะบล็อก DM) ทันที

## ติดตั้ง (ผู้ดูแล HOSxP)
ต้องมีบัญชีฐานข้อมูลสิทธิ์ SELECT, UPDATE บน `sys_app_script` (+ SELECT ตาราง pp_special, pp_special_type, lab_head,
lab_order, opitemrece, ovst) · รหัสผ่านถามแบบซ่อน ไม่เก็บลงไฟล์

```
cd <โฟลเดอร์ NCD_Dashboard>
python hosxp_alert\install_remission_alert.py check   --host IP_ฐานทดสอบ --db hos_test --user ชื่อผู้ใช้ฐาน
python hosxp_alert\install_remission_alert.py install --host IP_ฐานทดสอบ --db hos_test --user ชื่อผู้ใช้ฐาน
```
ทดสอบใน HOSxP ที่ต่อฐานทดสอบตามตารางด้านล่าง ผ่านแล้วจึงติดตั้งฐานจริงช่วงคนน้อย:
```
python hosxp_alert\install_remission_alert.py check   --host IP_ฐานจริง --user ชื่อผู้ใช้ฐาน
python hosxp_alert\install_remission_alert.py install --host IP_ฐานจริง --user ชื่อผู้ใช้ฐาน
```
ตัวติดตั้งสำรอง script เดิมไว้ใน `hosxp_alert\backups\` ก่อนเขียน ต้องพิมพ์ `YES` และพิมพ์คำสั่งย้อนกลับให้ ·
**เปิดผู้ป่วยจริง 1 รายทันทีหลังติดตั้ง** ถ้าข้อความ SOS/Sepsis ไม่ขึ้นเลย = script หยุดเงียบ ให้ย้อนกลับทันที:
```
python hosxp_alert\install_remission_alert.py rollback --host IP_ฐานจริง --user ชื่อผู้ใช้ฐาน --backup hosxp_alert\backups\<ไฟล์>.pas
```
เอาเฉพาะบล็อก DM Remission ออก (Sepsis คงเดิม): คำสั่ง `remove` · ดู script ที่จะได้โดยไม่ต่อฐาน: `preview --from <ไฟล์.pas>`

**ห้ามติดตั้งบน replica** · **ถ้าติดตั้ง/อัปเดตตัวเตือน Sepsis ใหม่ (`install_alert.py`) บล็อกนี้จะหาย ให้รัน `install` ของไฟล์นี้ซ้ำ**

ค่าที่ตั้งได้: `--lab` (HbA1c, 271) `--drugs` (icode ยาลดน้ำตาลทุกชนิด — ค่าเริ่มต้น 13 รหัสของ รพ.วังน้ำเขียว ต้องตรงกับ `NCD_DRUG_DM`)
`--pp` (1I20) `--cut` (6.5) `--due` (90) `--max` (180)

## ตารางทดสอบ (ฐานทดสอบ)
หา HN ตัวอย่างในฐานทดสอบ (แสดงบนจอเครื่องนี้เท่านั้น ห้ามถ่ายภาพ/ส่งต่อ):
```
python hosxp_alert\install_remission_alert.py samples --host IP_ฐานทดสอบ --db hos_test --user ชื่อผู้ใช้ฐาน
```
