# ความหมายคอลัมน์ HDC ที่แอปใช้ (ระดับอำเภอ 3025 = วังน้ำเขียว)

ดึงจาก `https://opendata.moph.go.th/api/report_data` (ผลรวมแถวของอำเภอ แยกตามหน่วยบริการ `hospcode`)
**สถานะ: ความหมายด้านล่างสืบทอดจากแอป `health_threat_app` ที่ใช้งานอยู่และเทียบกับ HDC แล้ว แต่ยังไม่ได้ยืนยันกับพจนานุกรมข้อมูลทางการของ HDC** — ข้อที่ไม่แน่ใจไม่แสดงบนหน้าเว็บ

| ตาราง | คอลัมน์ที่ใช้ | ความหมายที่ใช้ | สถานะ |
|---|---|---|---|
| `s_ht_control` | `target`, `bp`, `result` | `target` = ผู้ป่วย HT ในเขต · `bp` = วัดความดัน ≥2 ครั้ง · `result` = ควบคุมได้ (จึงใช้ ควบคุม% = `result ÷ bp`, ครอบคลุมการวัด% = `bp ÷ target`) | ใช้ตามแอปเดิม |
| `s_dm_control` | — | **ไม่แสดง** (แอปเดิมพบว่าคอลัมน์ HbA1c ของ HDC ไม่สอดคล้องกัน) | ไม่ใช้ |
| `s_ht_screen`, `s_dm_screen` | `target`, `result` | `target` = ประชากรเป้าหมายคัดกรอง (≥35 ปี) · `result` = ได้รับการคัดกรอง → คัดกรอง% = `result ÷ target` | ใช้ตามแอปเดิม |
| `s_ht_incidence`, `s_dm_incidence` | `result`, `result10`…`result09` | ผู้ป่วยรายใหม่ของปีงบ และแยกรายเดือนเรียง ต.ค.→ก.ย. (ผลรวมรายเดือน = `result` ตรวจแล้ว) | ยืนยันจากตัวเลข |
| `s_ht_pop_age`, `s_dm_pop_age`, `s_copd_pop_age`, `s_stroke_pop_age` | `result_group1..5` | จำนวนผู้ป่วยในเขตแยกกลุ่มอายุ (แสดงเฉพาะผลรวม ไม่แสดงรายกลุ่มเพราะยังไม่ทราบช่วงอายุของแต่ละกลุ่ม) | ใช้เฉพาะผลรวม |
| `s_copd_incidence` | `result` และรายเดือน | COPD รายใหม่ | ยืนยันจากตัวเลข |
| `s_ckd_stage_typearea` | `stage1..stage5` | จำนวนผู้ป่วย CKD ตามระยะ (พื้นที่ typearea) | ใช้ตามชื่อคอลัมน์ |
| `s_kpi_ckd_screen` | `target`, `result` | คัดกรอง CKD% = `result ÷ target` | ใช้ตามชื่อคอลัมน์ |
| `s_kpi_ckd_egfr`, `s_kpi_ckd_bp`, `s_kpi_ckd_acei_arb`, `s_kpi_ckd_hb`, `s_kpi_ckd_hba1c`, `s_kpi_ckd_statin`, `s_kpi_ckd_upcr` | `target`, `result` | ตัวชี้วัดคลินิกชะลอไตเสื่อม **ระดับ รพ.** (มีแถวเดียว hospcode 10894) ร้อยละ = `result ÷ target` · ความหมายเกณฑ์ใช้ตามชื่อตาราง — ใส่เป้าเฉพาะ eGFR (≥66%) และ ACEI/ARB · **ไม่ใช้** `target1..4`/`result1..4` (ยังไม่ทราบว่าเป็นไตรมาสหรือกลุ่มย่อย) | ใช้ตามชื่อตาราง |
| `s_kpi_ckd_incidence` | `result` | ผู้ป่วย CKD รายใหม่ของปีงบ แยกรายหน่วยบริการ (แสดงเฉพาะจำนวน — `target` ยังไม่ทราบความหมาย ไม่คิดร้อยละ) | ใช้ตามชื่อตาราง |
| `s_dm_remission_coverage` | `b`, `b1`, `b3`, `b4`, `a`, `a2`, `a3` | DM remission ตัวชี้วัด 10.2 (เอกสาร HDC กองโรคไม่ติดต่อ 13 ก.พ. 2569): `b`=B2 ผู้ป่วย DM ชนิด 2 ที่เข้าเกณฑ์ · `b1`=B1 สมัครใจเข้าร่วม clinic (1I20) · `b3`/`b4` เข้าร่วม ไม่มี/มีภาวะแทรกซ้อน · `a`=A1 เข้าสู่ระยะสงบ · `a2`/`a3` แยกตามภาวะแทรกซ้อน · แถวแยกตาม hospcode+areacode (รวมตาม hospcode) · ค่าเป็นสตริงตัวเลข · ไม่รวม `__pvcode` | ยืนยันจากเอกสาร |
| `s_ht_screen_risk`, `s_dm_screen_risk` | `target`, `result`, `normal`, `risk`, `high_risk`, `ill` | ผลคัดกรองประชาชน: ได้รับการคัดกรอง (`result` จาก `target`) แยก ปกติ/เสี่ยง/เสี่ยงสูง-สงสัยป่วย/ป่วย · ร้อยละคิดจาก `result` (ผลรวมกลุ่มไม่เท่า `result` พอดี — ป่วยอาจรวมผู้ป่วยเดิม) · ไม่ใช้ `ill_1` | ใช้ตามชื่อคอลัมน์ |
| `s_dm_foot` | `target`, `result`, `abnormal1` | ตรวจเท้า DM% = `result ÷ target` · พบผิดปกติ = `abnormal1 ÷ result` (`normal1 + abnormal1 = result` ตรวจแล้ว) · ไม่ใช้ `target1`/`result1`/`*2` | ยืนยันจากตัวเลข |
| `s_asthma_incidence`, `s_ihd_incidence` | `result`, `target`, รายเดือน (หืด) | ผู้ป่วยรายใหม่ · `target` = ประชากร → อัตราต่อแสน · ไม่ใช้ `target1`/`result1` ของ IHD | ใช้ตามชื่อคอลัมน์ |
| `s_stemi_death` | `targetq1..4`, `resultq1..4` | ผู้ป่วย STEMI รายไตรมาส / เสียชีวิต (ระดับ รพ.) — ผลรวม `targetq` = `visit_all` ของ `s_kpi_stemi` | ยืนยันจากตัวเลข |
| `s_kpi_cvd_risk` | `target`, `result` | ตัวชี้วัด CVD Risk ของ DM/HT — **ยังไม่ยืนยันนิยามตัวตั้ง/ตัวหาร** แสดงร้อยละโดยไม่ใส่เป้า | ใช้ตามชื่อตาราง |
| `s_kpi_stemi` | — | **ไม่ใช้** (ตัวเลขน้อยมาก ยังไม่ทราบความหมาย target1..4) | ไม่ใช้ |
| `s_dm_remission` | — | **ไม่ใช้** (ตารางรุ่นเก่า มีเพียงบางหมู่บ้าน) | ไม่ใช้ |
| `s_dm_ckd` | — | **ไม่แสดง** (คอลัมน์ `target_1`/`result_1` ยังตีความไม่ได้) | ไม่ใช้ |
| `s_dm_retina_kpi` | `target`, `result` | ตรวจจอประสาทตาในผู้ป่วย DM% = `result ÷ target` (ค่าปีงบ 2569 มีน้อยมาก — ระวังการตีความ) | ใช้ตามชื่อคอลัมน์ |

ข้อควรระวัง: ข้อมูล HDC เป็นนิยามของ HDC (ทั้งอำเภอ ตามทะเบียนผู้ป่วยในเขต) ต่างจาก HOSxP ที่นับเฉพาะผู้มารับบริการ รพ. — ห้ามนำสองฝั่งมาหักล้างกันตรง ๆ
