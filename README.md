# NCD Dashboard — แดชบอร์ดกลุ่มโรคไม่ติดต่อเรื้อรัง (รพ.วังน้ำเขียว)

> **เวอร์ชัน 0.1.10** — ใช้กับโรงพยาบาลที่ใช้ HOSxP · ติดตั้ง/ตรวจก่อนใช้: [INSTALL.md](INSTALL.md) (อ่านข้อ 0 “ก่อนนำไปใช้” ก่อน) ·
> การเปลี่ยนแปลง: [CHANGELOG.md](CHANGELOG.md)

แอป Flask 7 หน้า — ภาพรวม, ความดัน (HT), เบาหวาน (DM), ไตเรื้อรัง (CKD), วาร์ฟาริน (Warfarin), COPD/หืด, หลอดเลือดสมอง/หัวใจ (CVD)
ปุ่มสลับ **HOSxP (รพ.)** / **HDC (ทั้งอำเภอ)** · ตัวกรองปีงบประมาณ/ไตรมาส/เดือน · พิมพ์/PDF · โทนสีคราม–ม่วง อ่านง่ายบนแท็บเล็ต

- ข้อมูล รพ. ดึงสดจาก HOSxP (MariaDB `hos`) แบบอ่านอย่างเดียว · ข้อมูลอำเภอจาก HDC (MoPH Open Data) **ดึงวันละครั้งเบื้องหลัง**
  ดึงไม่ได้หรือปีงบใหม่ยังไม่มีข้อมูล → แสดงข้อมูลล่าสุดที่เคยดึงไว้พร้อมแจ้งเตือน
- **ตัวชี้วัด HDC เพิ่มเติม:** คลินิกชะลอไตเสื่อม 7 ข้อ, DM remission (ตัวชี้วัด 10.2), ผลคัดกรองความเสี่ยง HT/DM, ตรวจเท้า DM,
  หืด/IHD รายใหม่, STEMI และอัตราตาย, CVD risk
- **ชะลอไตเสื่อม (HOSxP):** ACEI/ARB, Microalbumin, ภาวะซีด, HbA1c ใน DM ที่มี CKD, Admit ซ้ำ ≤28 วัน
- **DM remission + ติดตามการเบิกงบบริการ:** สถานะรายคนตามเกณฑ์เบิก (ถึงกำหนดเจาะครั้งที่ 2/3, รอครบกำหนด, ยังได้ยา) และยอดเบิกที่ยืนยันผลในช่วง
- **รายชื่อผู้ป่วยเปิดได้เฉพาะเครือข่าย LAN ของ รพ.** — ทุกหน้าโรคกดดูรายชื่อตามกลุ่มได้ (จำนวนตรงกับตัวเลขบนหน้า)
  จากอินเทอร์เน็ต/proxy ภายนอกเห็นเฉพาะตัวเลขรวม (403 โดยไม่อ่านฐาน) · `/api/*.json` ไม่มี HN
- **หน้าต่างเตือน DM Remission ใน HOSxP** (`hosxp_alert/`) — เตือนห้ามสั่งยาลดน้ำตาลและวันนัดเจาะ HbA1c ครั้งถัดไป ต่อท้าย script เตือน Sepsis เดิม
- ทุกตัวเลขต้องสืบย้อนถึง query ได้ — ตัวชี้วัดที่ไม่มีแหล่งข้อมูลแสดง "ไม่มีข้อมูล"
- **ตรวจก่อนใช้:** หน้า `/check` และ `python setup_check.py` เทียบรหัสที่แอปใช้กับข้อมูลจริงของ รพ. · แถบเตือนบนหน้าหลักจนกว่าตั้ง `NCD_DATA_AUDITED=1`

## เริ่มใช้งาน
```bash
pip install -r requirements.txt
cp .env.example .env     # กรอกค่าฐานข้อมูล (บัญชีอ่านอย่างเดียว)
python setup_check.py    # ตรวจความพร้อม
python app.py            # http://127.0.0.1:5400/
```

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `app.py` | routes `/`, `/<หน้า>`, `/api/<หน้า>.json`, `/list/<หน้า>/<กลุ่ม>` (เฉพาะ LAN), `/check`, `/healthz` · PrefixMiddleware |
| `queries/clinic_lists.py`, `remission.py`, `remission_claim.py` | รายชื่อผู้ป่วยตามกลุ่ม · DM remission · เกณฑ์เบิกงบ DM Remission |
| `hosxp_alert/` | หน้าต่างเตือน DM Remission ใน HOSxP + ตัวติดตั้ง (check / install / remove / rollback) — ดู README ในโฟลเดอร์ |
| `queries/<หน้า>.py` | `build(p, src, opts)` ของแต่ละหน้า → dict รูปแบบเดียวกัน (ดู `pages.py`) · `common.py` = SQL ร่วม · `hdc_views.py` = มุมมอง HDC |
| `classify.py` | ตรรกะแบ่งกลุ่มทางคลินิก (BP, HbA1c, INR, ระยะ CKD, TTR) — ฟังก์ชันบริสุทธิ์ |
| `periods.py` | ปีงบประมาณ/ไตรมาส/เดือน |
| `hdc.py` | ดึง/แคช HDC ระดับอำเภอ (ทนต่อ API ล่ม/429) |
| `check.py`, `setup_check.py` | Data Audit และตรวจสภาพแวดล้อม |
| `config.py` | รหัส/เกณฑ์ทั้งหมดอ่านจาก env |
| `templates/`, `static/` | หน้าเว็บ (กราฟ SVG/CSS ฝั่งเซิร์ฟเวอร์ ฟอนต์/ไอคอนในเครื่อง ไม่พึ่ง CDN) |

## ทดสอบ
```bash
python -m pytest -q tests                                # ไม่ต่อฐานจริง
NCD_LIVE=1 python -m pytest -q tests/live                # ต่อ HOSxP จริง (อ่านอย่างเดียว)
```
